# Vogel Consultoria Landing

Landing page corporativa desarrollada con Vue 3, Vite y Tailwind CSS.

## Instalacion y ejecucion

```bash
npm install
npm run dev
```

## Estructura sugerida para imagenes en assets

```text
src/assets/
  logo-vogel.png
  hero/
    network-pattern.png
    dashboard-mockup.png
  services/
    systems-icon.svg
    dashboards-icon.svg
    automation-icon.svg
    ai-icon.svg
    workshops-icon.svg
```

## Produccion

```bash
npm run build
npm run preview
```
